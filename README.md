# Примеры

## Входные данные

| Файл | Что это |
| --- | --- |
| `input/manometer-dm02.json` | Пример из текста задания. Описание в нём оборвано многоточием, и сервис это отмечает |
| `input/demo-pressure-transmitter.json` | **Вымышленный демонстрационный прибор.** Нет производителя и класса точности, часть характеристик есть только в описании |
| `input/invalid-empty.json` | Некорректный вход: писать карточку не из чего |

## Результаты

В `output/` лежат `.md` и `.json` для первых двух файлов.

> **Важно: эти результаты получены без обращения к настоящему API.** При разработке не было ключа, поэтому ответы модели написаны вручную по системному промпту и лежат в `tests/fixtures/`. Затем они прошли через весь сервис: HTTP-клиент, проверку фактов, сборку таблицы и Markdown. Поэтому в `meta.model` указано `offline-fixture`. Качество реального ответа LLM эти файлы не подтверждают.

Чтобы получить настоящий результат, укажите ключ в `.env` и выполните:

```bash
python -m cardgen generate examples/input/manometer-dm02.json examples/input/demo-pressure-transmitter.json --out-dir examples/output
```

После этого обновите этот раздел.
